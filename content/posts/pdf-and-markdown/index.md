这是站点功能的示例笔记。

## Markdown 与资源

导入一份 Markdown 时，把图片文件夹一起选中，或将它们打成 ZIP。单个 Markdown 文件只包含图片路径，不包含图片数据。

## PDF 的两种用法

扫描件保留原样，不进行 OCR。有文字的 PDF 可以转换成草稿，再检查段落与图片；复杂页面会保留页面图像，原文件也一直保留。

## 备份

浏览器草稿保存在当前浏览器，清理网站数据会丢失。文章包包含 Markdown 和资源，适合作为可携带的本地副本。
